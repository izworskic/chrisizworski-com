# U.P. waterfall photography, verified batch 6
Research and change date: 2026-11-14. This batch adds four waterfall-specific photographs with original image credits and explicit commercial-use licensing. It does not change any trail, access, location, visitor advice, ad placement, or monetization code.

## Added photographs

**Rainbow Falls — Gogebic County, Black River**
- Commons: https://commons.wikimedia.org/wiki/File:Rainbow_Falls_Michigan.jpg
- Credit: HuntersLab616. Self-licensed CC BY-SA 4.0. Original 4032 × 2268; display 960 × 540 derivative.

**Upper Hungarian Falls — Tamarack City, Dover Creek**
- Commons: https://commons.wikimedia.org/wiki/File:Hungarian_Falls,_Upper_Falls.png

## Held / rejected from this release
- **Lower Hungarian Falls**: only clearly tier-named verified commercial-reuse photo is 544 × 749 and shows almost no waterfall beyond a steep tree-covered cliff. Not suitable as the guide's lead image. No borrowed Upper/Middle photo.
- **Yellow Dog Falls**: licensed images show different reaches of the Yellow Dog River and West Branch; exact catalog waterfall identity is unresolved. No substitution.
- **Fumee Falls**: visible third-party image was heavily illustrated/processed and no clear authentic photographer reuse license was confirmed. No image fabricated from it.
- **Silver River Falls / Jacob's Falls / Nonesuch Falls**: a precise, rights-cleared photograph of the exact named waterfall is not yet established.
- **Superior Falls**: Commons' named exact asset currently located is a 500 × 333 animated GIF, not a suitable static lead photograph.
- **Little Union Gorge Falls**: Commons has a broad gorge cascade view but not a confidently identified waterfall tier; no automatic attribution of that image to the exact natural feature.
