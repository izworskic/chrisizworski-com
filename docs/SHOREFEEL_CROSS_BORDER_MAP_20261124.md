# ShoreFeel investment 3: one cross-border temperature map
Date: 2026-11-24. Stacked on intelligence PR #1915 and registry PR #1913; not deployed.

## Experience choice
Primary job: choose a beach on either side of the border and learn what the air may feel like. Compared a single geographic canvas with a forecast-table-first experience. Map-first wins because geographic discovery and nearby comparisons are the visitor's decision. Keep a bounded keyboard-accessible list and one selected report. The existing U.S. page is the master entry point, not a new URL. Existing regional reports and guide URLs remain. The 16 static park links, old U.S. directory and official sources remain as a no-JavaScript or catalog-failure fallback; do not initialize both interactive explorers together. Existing separate Michigan and Ontario entry points are not yet consolidated.

## Implementation
- All 1,050 map-eligible registry records are represented in initial view, subject to actual browser verification. Screen-space grouping retains every record and uses a 68px minimum anchor separation; no geographic-grid centroid collisions. At maximum zoom, a group of coincident records remains selectable through the group list.
- Map-local touch dragging, pinch and 46px zoom controls; page pinch outside map preserved. No automatic popup obscuring the map. Tile failure retains the markers and list, with an explicit background warning.
- Search beach name, known town, county, region, lake or source identity. Search/region/lake filters fit matching places; selection is stable by registry ID. Legacy ?beach= keys resolve to the new selection. Canonical links remain unchanged.
- One selected detail uses existing official-provider endpoint with current/upcoming distinction, F/C unit switch, air, wind, optional NOAA water, actual hourly readings and local advisory/guide links. No invented numerical beach correction or swimming-safety verdict.
- The map shows numbered groups at wide zoom and current temperatures for individual markers when fetched. At zoom 8+, automatic requests are limited to 24 visible individual markers (batches of four, sequential), cancel stale viewport requests, and allow explicit additional loads. The rest retain selectable dots. It is not an all-beach live snapshot. Stale values expire, and unavailable values show dashes. No new Vercel function, scheduled job, database, paid API, ads or runtime dependency. The shared JSON is about 738 KB uncompressed including existing guide metadata; browser transfer and performance still need measurement.
- The Canada source attribution is preserved. Regional Michigan advisories and scores remain in the dedicated Michigan report. Ontario inventory remains 30 curated entries, not comprehensive coverage.
