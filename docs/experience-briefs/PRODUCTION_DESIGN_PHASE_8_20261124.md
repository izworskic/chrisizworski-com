These are source-confirmed defects; the browser baseline comparison is required before calling the actual rendered defect verified.

## Bounded implementation and proof

Retain the existing independent town search, NWS source, time semantics, region geometry, current report ranking, tabular typography, map and published SEO metadata. Correct selected-scope empty language, distinguish explicit 0 in. observation from missing report, retain historical statewide context only when no region is selected, and keep failure/stale searches from turning into a current answer. No new global theme; use existing native HTML/CSS/JS. Do not introduce Python, Rust, Java, React or new backend for a presentation defect.

Source-level and fixture tests plus same-run before/after browser captures at 390px; 360/390/768/1280/1440 checks for current/empty/recovery, explicit zero report, historical, stale, failed and no-JS states. Browser uses synthetic report fixtures and pinned Leaflet with local tile fixtures. It does not certify actual NWS, provider tiles, current snowfall or site-wide quality. Real map/visitor metrics remain separate. Targeted workflow is path-scoped, isolated and uses existing static server; no production infrastructure. Full repository gate and public audit, screenshot review and owner approval required before merge.
