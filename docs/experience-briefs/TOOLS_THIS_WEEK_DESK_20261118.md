## Research

- OpenSnow favorites (support.opensnow.com/getting-started/favorites, checked 2026-11-18): saved locations as the starting screen so deciding where to go is easy; separate seasonal lists. Lesson: a visitor's own tools and the current season belong first. Not copied: accounts, alerts, 15-location limits.
- NPS Find a Park (nps.gov, checked 2026-11-18): one front-door search by activity, state or topic. Lesson: search first. Concept B (intent tiles) took this further and was not chosen.
- GOV.UK / Scottish Government search guidance (see the hub search brief): results must appear where a phone user is looking.

## Concepts

- **A. This-week desk (selected by owner):** search → existing monthly picks ("Worth your attention in November", generated by `scripts/build-seasonal-discovery.py`) → "Your tools" (stars, this browser only) → sticky jump menu → every tool, all groups open, compact cards → editorial sections.
- **B. Ask first:** intent tiles opening a shortlist, search underneath. Costs every visitor an extra tap.

Originality: no new page scaffold; existing sections, voice and card design are kept and re-ordered around the visitor decision. **Gate: PASS.**

## Interaction contract

| Action | Result | Fallback |
| --- | --- | --- |
| Star / unstar a card (tap or Enter/Space) | Tool appears first in "Your tools", newest first; persists in this browser | No JS or blocked storage: no stars, section stays hidden |
| Remove (✕) in "Your tools" | Unstars the tool | — |
| Jump menu (sticky on phones, swipeable) | Scrolls to the group heading, not under the menu (`scroll-margin-top`) | Plain anchors |
| Search / chips | Unchanged from PR #1766 | — |

Analytics: anonymous `tool_star` event with the tool id and add/remove only.
