# Chris Izworski Search Authority Portfolio

Updated: August 22, 2026 (America/Detroit)

## The objective

The goal is bigger than ranking a personal website or filling the first 30 results for `Chris Izworski`.

The portfolio should make Chris Izworski a durable, machine-understandable authority behind a network of genuinely useful Michigan and Great Lakes resources. The branded SERP should become crowded because the work is real, distinct, useful, cited, and independently corroborated.

**Useful tools create demand. Evidence and earned authority create trust. The network compounds both.**

This portfolio operates alongside `docs/SEARCH_STRATEGY.md`. The search strategy governs page-level SEO discipline. This document decides **where the next unit of effort should go across the whole ecosystem**.

## Portfolio scoring

Every meaningful property, tool, guide, cluster, or proposed build should be considered against the same 100-point portfolio model:

| Dimension | Weight |
| --- | ---: |
| Demand and search opportunity | 20 |
| Current rank leverage | 15 |
| Unique utility and data moat | 15 |
| Topical authority and linkability | 15 |
| Network multiplier | 10 |
| Chris Izworski entity contribution | 10 |

Technical health, factual accuracy, canonical integrity, and active-experiment protection are **hard gates**, not points that can be traded away for growth.

## Action classes

Every priority should have one clear action class.

### Protect

The asset is already winning or is inside a clean measurement window. Keep it reliable and do not churn search-facing surfaces.

### Protect, then push

The opportunity is obvious, but the current experiment must finish first. Queue the next treatment rather than contaminating the measurement window.

### Push rank

Demand and conversion are already credible. The work is authority, useful depth, evidence, contextual links, original data, and better network support — not another adjacent keyword URL.

### Repair SERP conversion

The page has meaningful impressions and a useful rank but weak CTR. Diagnose the query family and actual SERP before changing the title, description, H1, first answer, or schema.

### Diagnose zero-click

Strong rank plus no clicks can mean Google is already answering the query directly. Determine whether the page needs a richer decision, whether the query is economically useful, and whether traffic is a realistic objective.

### Expand authority

The asset has a real moat but needs stronger evidence, original synthesis, sources, citations, inbound links, or supporting coverage.

### Connect

The property is useful but under-discovered. Improve contextual handoffs, entity linkage, feeds, and its place in the ecosystem before making more pages.

### Seasonal build

Prepare the system before demand arrives: data sources, crawlable answer, methodology, internal links, authority, and measurement should be ready before the first weather event or seasonal spike.

### Launch-gated

The idea belongs in the portfolio, but production, canonical, source, and measurement gates must pass before it receives crawlable central promotion.

## Branded SERP is a portfolio outcome

The exact-name query currently shows a 1.0 average position in the fresh Search Console snapshot, and the homepage averages 1.59. That means the strategy must **not force `/chris-izworski/` to displace a homepage that is already winning**.

The branded objective is:

1. A first-party `chrisizworski.com` surface owns position #1.
2. The homepage remains preferred while it is the strongest observed first-party winner.
3. The identity page remains the canonical deep biography/entity surface.
4. Distinct owned properties, author pages, professional profiles, and earned third-party references occupy as much of the top 30 as they can legitimately earn.
5. No thin duplicate page is created simply to occupy another result slot.

The standing occupancy goals remain 8/10, 15/20, and 20/30, with 30/30 as the stretch goal.

## Independent authority program

Owned sites prove that the work exists. Independent sources are what make the authority harder to dismiss.

The entity baseline already tracks Wikidata, LinkedIn, GitHub, ORCID, YouTube, Medium, and About.me. The next high-value surfaces are legitimate, relevant external references rather than another owned microsite:

- APCO or NENA speaker/member/author surface;
- Muck Rack author profile tied to published work;
- Prepared/Axon speaker or author coverage when a real public surface exists;
- government and association event pages;
- interviews, podcasts, conference programs, and credible news coverage;
- Scholar/Semantic Scholar linkage where published work genuinely qualifies.

These surfaces should corroborate the same person, work, employer, expertise, and canonical site without turning every profile into identical SEO copy.

## AI search is part of the same system

That is an important opportunity, but it is not permission to fill pages with artificial FAQ prose. The next eligible improvements should make answers better for both people and models: direct, self-contained, source-aware, current where needed, and clear about uncertainty.

## Operating cadence

### Weekly

Review fresh Search Console signals, source failures, index/canonical anomalies, and experiment eligibility. Emerging queries must map to an existing owner before a new URL is proposed.

### Monthly

Re-score the portfolio by cluster and action class. Take a top-30 `Chris Izworski` SERP snapshot, classify every result, inspect independent entity surfaces, and move priorities up or down based on evidence.

### Seasonally

Start meaningful readiness work 6-10 weeks before demand. The first snow, first freeze, first fall-color spike, or first spring planting surge should not be the day the site starts preparing.

## What this changes about future builds

A new idea no longer wins because it sounds interesting or because a keyword exists. It should beat the opportunity cost of improving an existing near-page-one asset.

Before building something new, ask:

1. Does it serve a genuinely distinct decision?
2. Is there demand evidence or a unique first-party utility?
3. Does an existing canonical already almost own this?
4. Can it connect to at least two useful portfolio nodes?
5. Does it strengthen a topical cluster or the Chris Izworski entity?
6. Can we measure success?
7. Is this better than pushing one of the P0/P1 assets already sitting near page one?

If the answer to the last question is no, improve the existing portfolio first.
