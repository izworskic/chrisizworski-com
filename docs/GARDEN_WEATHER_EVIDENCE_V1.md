# Garden weather evidence bridge

2026-11-24. Follow-up in PR #1901. No new production function, route, cron, provider account, paid service, build step, or page. Existing leafcutter weather handler adds an opt-in query mode, `/api/leafcutter-release-weather?mode=garden-evidence&site=bay-city`. No change to default leafcutter contract. Same two NWS requests per uncached lookup, same location resolver and cache policy. No visitor-facing call site added; future consumers must share one lookup, not poll.

## Weather evidence
NWS API reference: https://www.weather.gov/documentation/services-web-api . Existing hourly forecast, city/ZIP reference rather than property. Source URL, issue time, checked time, local day and time zone are preserved. A forecast issued more than 18 hours ago or after the current time is withheld. Only hourly intervals on the actual civil-day timeline count; complete spring/fall DST dates require 23/25 hours respectively. Conflicting temperatures for the same timestamp veto the hour. An incomplete day retains a remaining-hours low only, not a daily min/max. Same-local-day issue only for harvest-engine records, per the v1 contract. Sampled hourly extrema are not observed daily extrema. No automatic merge of regional forecasts with garden sensor observations. A current partial day blocks contiguous observed-plus-forecast accumulation; do not silently fill the gap. No live harvest date until that bridge and field validation exist. A full-day low is not an overnight minimum; no automatic application of paired-night offsets. The microclimate bridge returns regional reference evidence only.

## Historical climate replay
Reuses seven existing NASA Daymet v4 R1 CSVs (2021–2025; Bay City, Detroit, Grand Rapids, Kalamazoo, Traverse City, Marquette and Houghton), 1 km gridded daily extrema in Celsius, converted to Fahrenheit. Source: https://doi.org/10.3334/ORNLDAAC/2129 . No new downloads or source licensing expansion. Coordinates checked against reference catalogue; 365 days per source year, including the missing December 31 of leap year 2024, preserved. Historical replay runs the existing crop model on each year's weather for the same planting month/day; outputs five heat-threshold crossings (or explicit null), packet baseline and coverage. These are climate scenarios, NOT actual harvest observations, probability intervals or local forecast skill. OSU cultivar model values checked against tables 1, 2, 3, 5 and 6 at https://extension.oregonstate.edu/catalog/em-9305-vegetable-degree-day-models-introduction-farmers-gardeners . No general GDD50 substituted.
