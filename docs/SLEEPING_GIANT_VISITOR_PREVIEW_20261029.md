# Sleeping Giant Explorer — visitor experience preview, October 29, 2026

**Status:** Built and verified as an OFFLINE GitHub Actions artifact only. NOT committed under `public/`, not deployed, not indexable and not advertised as legal GPS navigation or current trip readiness. Feature lives in draft [PR #1273](https://github.com/izworskic/chrisizworski-com/pull/1273).

## Value delivered

The earlier GIS review exposed a fundamental visitor mistake: 3.3 km **Top of Giant named spur** versus **21.8 km complete parking-to-destination return**, and a genuine unknown ~0.6–0.8 km mapped route gap between the park's return distances and Ontario OTN geometry. Rather than hiding either uncertainty, the preview puts the trip decision first:

- Six permanently crawlable-in-future HTML route cards, still useful with JavaScript disabled: Top, Head, Nanabosho, Sea Lion, Middlebrun Bay Beach and Pass Lake Overlook, including honest full return distance, difficulty and actual availability of a published total-trip duration.
- A visitor input row for **available time** (2, 4, 8, 10 or 12 hours), **mode** (walk or bike-and-hike), and **interest** (short walk, summit, geology, beach, lake, challenge, lookout).
- Precomputed **70 combinations** generated by the **existing canonical Node.js `route-engine.cjs`**, not an independently invented browser decision model. Every per-route ranking and message is linked to that engine's exact duration classification. Unpublished trip durations and bike-hike travel times do not become false green windows.
- Four unsimplified GIS **read-only mapped outline** choices: Top, Head, Nanabosho and Sea Lion, with separate mode-coloured walking / legal cycling segments and a visually separate approximate OSM parking-area center. Middlebrun and Pass Lake are correctly shown as **not geospatially reconciled** rather than assigned fake lines.
- Source-backed signed South Kabeyun approach, bike cutoff/rack disclosure, permit advice, access unknowns, official alerts and the embedded full return distance.
- A field-guide visual treatment: original typography/CSS, accessible contrast and focus states, an adaptive dark-forest hero, full-width licensed landscape, six editorial route cards, a responsive map/summary panel, and readable short park-ranger prose.
- A documented photograph: Justin Meissen's **Top of the Sleeping Giant**, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Top_of_the_Sleeping_Giant.jpg), credited under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/). The background is a remote, optional decorative photo: the gradient background provides a graceful offline fallback. Image is visually cropped via CSS, with attribution.
- All links to park activity, trail evidence and alerts are external official references; there are **no Google Maps driving links**, route downloads, live weather grades, opening assurances, GPS turn guidance or invented duration estimates.

## Technical implementation

- `previews/sleeping-giant-explorer/index.template.html`: semantic, source-readable responsive page structure and static route fallbacks.
- `previews/sleeping-giant-explorer/explorer.css`: light destination cards, dramatic sea/forest field-guide aesthetic, phone/tablet/desktop layout, keyboard focus, reduced motion.
- `previews/sleeping-giant-explorer/explorer.js`: initializes from statically embedded, code-reviewed model; integrates rank changes and selection with safe DOM text updates; builds SVG research polylines only for four verified-source geometry options; does not fetch weather, geolocation, paid map tiles or a new navigation backend.
- `scripts/export-sleeping-giant-visitor-preview.mjs`: builds a **self-contained `index.html`** from read-only evidence inputs, 70 engine-backed decision states and four source-preserving GIS itineraries. Refuses to export if government geography flags, park access proof or live-state limitations are violated. Emits a JSON evidence summary.
- `tests/sleeping-giant-visitor-preview.test.js`: verifies source and mode truth, accurate planning engine parity, all six cards and metadata, no-script fallback, accessibility, parked trail geometry disconnects and no directions.
- `scripts/verify-sleeping-giant-browser.cjs`: actual Chrome desktop (1440 × 900), phone (390 × 844), JavaScript disabled. Exercises the default Sea Lion result, 12-hour cycling/summit choice, Top breakdown and map, and explicit **no mapped route** for Middlebrun. Verifies no horizontal overflow or browser errors. Screenshots uploaded by the dedicated PR workflow.
- `.github/workflows/sleeping-giant-engine.yml`: exports `sleeping-giant-topology-audit` (including `visitor-preview/index.html`), plus `sleeping-giant-visitor-browser-qa` (desktop and phone screenshots, map screenshots, browser report), while also running all original 59 full repository gates.

## Why not live yet?

The exact South Kabeyun **signed vehicle entry point** and continuous legal/public parking-to-OTN-start footpath are not source-certified. GIS spatial junctions are mathematically close, but legally signed bike-to-walk turn coordinates and live conditions remain unresolved. The weather assessment engine still has **no live ECCC acquisition adapter or cache**. A full interactive time-and-weather summit recommendation would therefore be premature.

A read-only visitor **comparison** could eventually be publishable without turn-by-turn directions, but it needs explicit owner signoff on canonical search intent, complete source notes, offline image reliability, shared site chrome and ad-loader build integration before adding to `public/`. Do not create a separate indexable URL or merge without those gates.

**Exactly one next development action:** Verify the South Kabeyun real parking-to-mapped-trail pedestrian connection from independent, authoritative map or signed facility evidence, and explicitly choose whether to ship the safe, read-only Explorer without directions pending full access proof.
