# Issue 1258 Batch 31 — Three Porkies public waterfall trails (2026-10-31)
No outreach, only public park and verified regional visitor sources.

## Routes and source gates
- **Trappers #102** state coordinate 46.732624,-89.884667 about 70m from regional waterfall map point. [Michigan DNR park trail map](https://www.michigan.gov/recsearch/-/media/Project/Websites/recsearch/documents/MapsO-S/porcupine_mountains_map.pdf?rev=ea21f7c022dc46edbd24f96d40021739) shows Little Carp River Road named parking and Little Carp River Trail, [DNR trail descriptions](https://www.michigan.gov/recsearch/-/media/Project/Websites/recsearch/documents/MapsO-S/PMWSP-trail-descriptions.pdf?hash=E9680F7DEC943301EBCD637007AAAB8C&rev=3d600b0d32ff4a589c9038c1ec545465) confirm wilderness river trail and [Western U.P. waterfall brochure](https://explorewesternup.com/wp-content/uploads/2026/04/WaterfallMapBro_2022_Drft6-opt.pdf) names the Trappers falls about **3 miles each way** via Overlooked and Greenstone. Not a roadside stop.
- **Explorers #104** state coordinate 46.735434,-89.886494 about 33m from regional guide, which identifies **just beyond Trappers on same Little Carp River Trail**. No independent exact mileage to Explorers; guide says more than 3mi each way and no invented final scramble. Both state GIS river strings say Carp River, but official named park route and regional brochure are LITTLE Carp River, not BIG Carp.
- **Shining Cloud #113** state coordinate 46.757774,-89.866956 about 99m from regional map. GIS erroneously spells SHINNING and labels river LITTLE CARP. [Michigan DNR authoritative trail description](https://www.michigan.gov/recsearch/-/media/Project/Websites/recsearch/documents/MapsO-S/PMWSP-trail-descriptions.pdf?hash=E9680F7DEC943301EBCD637007AAAB8C&rev=3d600b0d32ff4a589c9038c1ec545465) explicitly identifies **Shining Cloud on BIG Carp River Trail**. Long approach from M107 Lake of the Clouds: 5.3 + 2.9 = **8.2mi one way**; alternative from officially mapped Pinkerton Trailhead [park map](https://www.michigan.gov/recsearch/-/media/Project/Websites/recsearch/documents/MapsO-S/porcupine_mountains_map.pdf?rev=ea21f7c022dc46edbd24f96d40021739) via Pinkerton 2.6 + Lake Superior 1.3 + Big Carp rivermouth upstream 1.4 = **5.3mi one way**. This is 10.6–16.4mi round-trip strenuous trip, not a day-trip shortcut.
- All are inside [Michigan DNR Porcupine Mountains Wilderness State Park](https://www.michigan.gov/recsearch/parks/porkies), with state trail map, regional named waterfall route, no parking coordinate guessed from falls GPS. South Boundary Road and M107 seasonally close, visitor permit and live closures should be checked. No opening or flow guarantee.
