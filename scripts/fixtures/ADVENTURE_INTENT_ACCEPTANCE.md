# Adventure Finder deterministic intent acceptance questions

Authored for the rule-based, source-grounded intent matcher. These are **editorial
test examples**, not real search logs, unbiased user research, or an independent
scientific holdout. All positive destination IDs must exist as source-owned
HTML articles in public/michigan-destinations/index.html.

The six no-answer queries request facilities, guarantees, current conditions
or access details the curated destination field notes do not substantiate. A
correct result for those examples is **no supported match**, not an invented
service or predicted safe condition.

These prompts must be tested separately from both Hugging Face model cohorts
(12 original and 20 paraphrases). Do not optimize by silently editing the
acceptance data after reviewing outcomes. Create a new dated holdout for later
revisions and actual usability research before claiming generalization.
