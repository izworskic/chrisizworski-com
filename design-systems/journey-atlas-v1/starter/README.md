# Portable working starter

Open `index.html` directly in a browser (no build, dependencies, keys, accounts or tracking). The included JavaScript and CSS are exact copies of the deployed reusable runtime.

The two sample cards are illustrative editorial links to real documented destinations. They are not clearance to travel and no map is provided in the starter. Replace them with verified, credited place photography and an owning site's source-backed places, region/interest/time attributes, alternatives and official sources.

The live Circle Tour integration is the richer reference and connects optional `data-ja-add-stop` to its existing itinerary engine. Apply `FIELD_GUIDE_V1` for production visual and photo standards.
