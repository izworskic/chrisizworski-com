# Python OS initial candidate portfolio — hypotheses, not completed enhancements

| Candidate | Possible decision value | Scientific / engineering prerequisite |
| --- | --- | --- |
| Michigan phenology (pilot) | Honest daily evidence coverage and revision warnings | Existing archive; this pilot does **not** predict emergence |
| Garden pest forecast | Species- and crop-stage-specific risk windows | Official growing-degree-day thresholds, stage model, independent pest observations and treatment thresholds |
| Living garden planner | Compare seasonal succession and bed utilization | Plant lifecycle constraints, sunlight, validated spacing, optimization baseline |
| Rocket Launch Live | Reconcile mission identities and source change history | Official source priority, launch pad geodata, coverage, no fabricated viewing score |
| Great Lakes freighter tracker | Quantify historical passage windows with error bars | Licensed/credible AIS history, vessel identifiers and route-specific ground truth |
| Northern lights / lake-effect snow | Calibrated location/time verdict uncertainty | NOAA official forecasts and observed validation, distinguish forecasts from sightings |
| Michigan freeze-up / lake smoke | Historical windows and false-positive analysis | NOAA satellite ice/water provenance, observation-based freeze/steam-fog truth |
| Morel / trillium / maple sap | Local phenophase uncertainty | Separate species evidence, soil/sap observations and proper season-specific models |
| Upper Peninsula waterfalls | Verified visitor location/access routing | Authoritative land access, signed trailheads and field validation; no inferred paths |
| Migration and birding | Temporal movement and location-specific evidence | eBird/USA-NPN scope, effort bias, source permissions, independent field observations |

Before implementation, inspect real visitor question, measured traffic, existing JS suitability and licensing. Favor a meaningful incremental upgrade to a well-performing tool over creating new but unvalidated probabilities.
