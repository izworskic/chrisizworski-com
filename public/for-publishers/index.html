Publisher resources

Put a useful Michigan tool on your site.

These are free, lightweight Michigan and Great Lakes planning tools built by Chris Izworski. Use a compact widget, a clean source link, or the Fall Color RSS feed. There is no charge and no commercial requirement.

Privacy: the shared widget does not use cookies, geolocation, free-text visitor input or personal information on your site. It only loads public tool data and adds a publisher source tag when a visitor chooses to open a tool.

Copy-and-paste widget

Change aurora to any widget key above and replace YOUR_SITE with a short identifier for your publication or organization.

<div
  data-chris-tool-widget
  data-tool="aurora"
  data-source="YOUR_SITE"

How to use these

Use the tool where it genuinely helps your visitor make a decision. A Sault Ste. Marie page might use Soo Locks Live. A dark-sky lodging page might use Northern Lights Michigan. A marina or fishing page might use Great Lakes Buoys. A fall travel page can use the Fall Color widget or RSS feed.

These are not paid-link placements. Keep the tool only if it improves the page for your readers.
