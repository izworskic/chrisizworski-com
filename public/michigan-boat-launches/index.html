Great Lakes Boat Launch Finder

Find currently open, state-sponsored Michigan boating access sites that connect to the Great Lakes. Every pin and every routing link comes from the Michigan DNR facility record. No guessed launches. No fuzzy name matching. No hand-placed coordinates.

Accuracy rule: the source creates the launch.

This finder only displays records returned by the current Michigan DNR Parks and Recreation boating-access layer that are marked open and have Great Lakes access. If the source cannot be reached, the map stays empty rather than falling back to legacy coordinates.

Map pins use the latitude and longitude published in the Michigan DNR facility record. “Directions” uses that same DNR coordinate. This tool does not create or infer launch locations.

What qualifies for this map?

The live query is intentionally strict. A record must be a DNR boating access site, be marked Open, have a published latitude/longitude, and have a DNR Great Lakes access value beginning with “Yes.” Records flagged for review or marked reference-only are excluded from the interface.

What is not included automatically?

Private marinas, informal road-end launches, and municipal launches that are not in this DNR/state-sponsored dataset are not invented or inferred. They can be added later only through a separate supplemental registry with a named operator source and verified coordinate.
