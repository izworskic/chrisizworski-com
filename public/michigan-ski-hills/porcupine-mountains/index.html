How to interpret local lake-effect snow

Michigan lake-effect snow depends on wind direction, lake-air temperature contrast, fetch and the terrain downwind. Bands can move miles with subtle wind shifts. Forecast snowfall for a resort is not an on-mountain measurement.

Use NWS point forecasts for expected snow, a resort report for base depth, and NWS local storm reports only as nearby evidence. If this page says “wind aligned,” it describes climatological potential, not proof of a powder day.
