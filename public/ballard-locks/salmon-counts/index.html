Ballard Locks salmon FAQ

Which salmon species are counted?

The WDFW source used here publishes separate daily tables for Sockeye, Chinook and Coho passing the Ballard Locks fish ladder.

How fresh are the counts?

The live API calculates the age of each latest published count. This page shows the actual source date and does not silently turn an older observation into a same-day count.
