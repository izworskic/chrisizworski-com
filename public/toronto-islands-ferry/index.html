Questions worth asking before booking

Do I need to return from the same dock?

No. The city says its tickets include the return from any island dock. That dock still needs to have service when you want to leave.

Is the Billy Bishop airport ferry the same service?

No. This planner is for the city’s Toronto Island ferries departing from Jack Layton Ferry Terminal.
